### Onboarding

**As a founder setting up Sentinel**, I want to paste a messy paragraph about my
company ("We're a 25-person SaaS co, Mark runs sales, Lisa marketing, John eng, John
reports to me") and have it structured into an employee table automatically, so that
setup takes two minutes instead of thirty.

**As a founder**, I want to connect Slack once and have Sentinel pull the member list
and map it to my employees, so that task assignment resolves to real people rather
than names it has to guess at.

**As a founder**, I want to upload our SOPs, product docs, and past meeting notes, so
that the chat can answer questions about how we actually operate.

**As a founder**, I want to name the assistant and set its tone and follow-up
aggressiveness, so that it feels like part of my company rather than a generic bot.

### Capturing work

**As a founder after a meeting**, I want the transcript turned into a list of tasks
with owners and deadlines, each showing the exact sentence it came from, so that I
can verify it in seconds rather than trusting a black box.

**As a founder**, I want to type "get the Q4 forecast from Mark by Friday" and have
the owner, deadline, and title parsed out, so that manual entry is one line, not a form.

**As a founder**, I want tasks extracted from Slack threads and email, so that
commitments made outside meetings don't get lost.

**As a founder**, I want low-confidence owner assignments flagged rather than guessed,
so that "ask Mark" never silently goes to the wrong Mark.

### Approving

**As a founder**, I want every extracted task to wait in an approval queue before
anyone is contacted, so that the AI can never message my team on its own.

**As a founder**, I want to approve, edit, or reject each task in one click, so that
reviewing a meeting's output takes under a minute.

**As a founder**, I want high-confidence tasks to auto-approve once I trust the
system, so that the queue doesn't become its own chore.

### Delegating and chasing

**As an employee**, I want tasks to arrive as a Slack DM with what's being asked, who
asked, and when it's due, so that I don't have to learn a new tool.

**As an employee**, I want to report status by tapping a button — Done, In Progress,
Blocked, Need More Time — so that replying takes one second.

**As an employee who's blocked**, I want to add a short note about why, so that the
blocker reaches the founder with context rather than as a bare status.

**As a founder**, I want unanswered reminders to escalate to that person's manager
after a timeout, so that ignored tasks surface instead of quietly rotting.

**As a founder**, I want one morning digest rather than a notification per update, so
that I don't mute the thing I bought to reduce noise.

### Remembering and querying

**As a founder**, I want to ask "what did we decide about pricing in March, and has it
changed?" and get an answer with dates and rationale, so that I stop re-litigating
settled decisions.

**As a founder**, I want to ask "what's Mark working on" or "what's overdue" and get
exact answers from real task state, not a fuzzy guess.

**As a founder**, I want every answer to cite its source meeting or thread, so that I
can verify anything the system tells me.

**As a new employee**, I want to search the knowledge base for how we handle a given
situation, so that onboarding doesn't consume a senior person's week.

### Trust and accountability

**As a founder**, I want a full audit trail of what the AI did, when, and on what
input, so that I can explain any action it took.

**As a founder**, I want to see the knowledge graph grow over time, so that the
system's value is visible rather than abstract.
